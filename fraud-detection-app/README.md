# Healthcare Fraud Detection Application

AI-powered fraud detection system using multi-agent analysis.

## Quick Start

```bash
# From this directory
python api_server.py
```

Access at: http://localhost:8000

**Login:** admin / fraud2025

## Components

- **Web Server:** `api_server.py` (port 8000)
- **MCP Server:** `mcp_server.py` (stdio mode)
- **Training:** `main.py` or `build_artifacts.py`

See main project README for complete documentation.
